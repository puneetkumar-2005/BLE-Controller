🎮 Wireless controller using BLE
🔘 Button and joystick-based inputs
📡 Low-power wireless communication
⚡ Real-time command transmission
🔧 Uses Arduino pro mini and HM10 BLE module
🔄 Customizable controls and commands
🛠️ Suitable for robotics, RC projects, IoT devices, and other wireless applications



You can explore how I assembled it and make your own controller as per your needs.
It can be connected to an esp32 for receiving commands or also to a Laptop for playing games etc.
It is not yet recognized by devices as a standard game controller, but it functions reliably with simple games and applications that support basic input controls.
